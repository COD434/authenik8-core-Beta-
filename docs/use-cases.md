# Use Cases

Authenik8-core is designed for:

- SaaS backends with tenant-aware authorization.
- APIs that need revocable access tokens.
- Secure administrative systems.
- Applications requiring refresh replay protection.
- AI agents, workers, bots, and M2M callers with bounded scopes.
- Systems that need centralized audit and session-risk signals.
